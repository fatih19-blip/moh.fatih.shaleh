PORTOFOLIO KEGIATAN — VERSI VERCEL (LOGIN ADMIN DIPERBAIKI)

1. Ekstrak ZIP ini.
2. Unggah/replace file ke ROOT repository GitHub yang terhubung ke Vercel.
3. WAJIB ikut mengunggah folder api/ dan api/admin/. Folder api dibutuhkan untuk endpoint login dan penyimpanan.
4. Di Vercel > Settings > Environment Variables, isi:
   ADMIN_PASSWORD = Fatih123
   SESSION_SECRET = rahasia acak minimal 32 karakter
5. Save lalu Redeploy.
6. Untuk menyimpan konten dan foto, buat Blob Store di Vercel Storage dan hubungkan ke project.
7. Tes pengaturan di /api/health. Baca README.md untuk panduan lebih lengkap.

Halaman admin: /admin.html atau /admin
Password: Fatih123 (setelah environment variable diatur)
Jangan upload file .env atau menyimpan rahasia sesi di kode website.
