Ubah konten, lalu klik tombol terbitkan. Website akan memperbarui file di GitHub dan Vercel akan melakukan deployment otomatis.

Buat token di GitHub → Fine-grained tokens. Batasi hanya ke repository ini dan beri izin Contents: Read and write. Jangan kirim atau bagikan token kepada siapa pun. Token hanya dipakai saat tombol terbitkan ditekan.

Sesudah berhasil, tunggu deployment Vercel selesai (biasanya satu atau beberapa menit). Perubahan ditulis ke index.html di repository yang dipilih.
